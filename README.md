   - `RECIPIENT_PHONE` : `01735698076`
3. ডিপ্লয় শেষ হলে Render এর ওয়েব লিঙ্কে গিয়ে একবার WhatsApp Web এর **QR কোডটি স্ক্যান করে নিন**!
